## Kiểm tra

Trước khi sửa, URL `/css/style.css` trả về 404; tệp CSS thực tế nằm ở thư mục gốc. Đã sửa đường dẫn trong HTML. Cũng sửa `type="texr"` thành `type="email"` và lỗi gõ `bacground-color` trong CSS.

Các sửa đổi mới đang ở máy local, chưa push. Cần push lên `main`, chờ GitHub Pages cập nhật, rồi kiểm tra lại trang và CSS tại `/style.css`. Không đính kèm ảnh hoặc video theo yêu cầu.

## Lưu ý

Form chỉ là mô phỏng, không gửi email hay lưu dữ liệu. Nút kiểm tra chưa có chức năng vì bài dùng HTML/CSS thuần.
